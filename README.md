# Customer Churn Prediction
ML project to predict customer churn using XGBoost.

## Libraries Used
pandas, numpy, scikit-learn, xgboost, streamlit

## Project Structure
- notebooks/ → EDA, Preprocessing, Model Building
- app/app.py → Streamlit Web App
- models/ → Saved ML Models

## How to Run
streamlit run app/app.py
